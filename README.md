# Wild Trace (prototype)

Camera trap game made with p5.js for our Gamified Learning project.

Put 2 cameras around the reserve, wait for the night, then find the photo that shows what's wrong.

Open `index.html` in a browser or paste `sketch.js` into the p5.js web editor.
